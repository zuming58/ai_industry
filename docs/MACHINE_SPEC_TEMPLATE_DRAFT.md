# MachineSpec Excel Template Draft

## 1. 文档状态

MachineSpec Template v1 的工作表、列名、代码规则和枚举已作为 M1 代码契约实现并自动验证。黄金项目到位前它属于“代码冻结、黄金验收待进行”；后续差异通过新模板或 Schema 版本演进，不回写或静默改变已锁定规格。

## 2. 模板原则

- 用户从 Agent 当前项目下载模板，不能以任意自定义 Excel 直接作为正式输入；
- 模板绑定项目、PLC 目标、模板版本和 MachineSpec Schema 版本；
- 空白正式模板与完整填写范例分离；
- 必填表缺失会阻断，选填报警/异常为空不阻断；
- 固定工作表和列名不可修改，用户数据区域可编辑；
- Excel 是编辑载体，导入后转为版本化 MachineSpec；
- 每个对象使用稳定 ID，显示名称与 ID 分离；
- 时间、位置、速度等数值必须带明确单位；
- 所有引用在导入时检查，不靠大模型猜测；
- 模板每次变更有版本和迁移策略。

## 3. 工作表草案

### Instructions

包含填写顺序、必填/选填说明、ID 原则、单位、下拉项、颜色含义和常见错误。正式模板不在业务表中混入示例行。

### Project（必填）

职责：项目、目标 PLC、工程软件、目标节拍和规格元数据。

候选字段类别：项目 ID/名称、PLC 品牌/系列/型号、软件版本、程序语言偏好、目标节拍、单位体系、备注。

### Components（必填）

职责：工站、机构、伺服、气缸、变频器及其他执行元件。

候选字段类别：稳定 ID、显示名称、工站/父级、元件类型、控制模板、机械资料引用、基本参数。

### Signals（必填）

职责：DI/DO/AI/AO、内部变量和通信信号及其元件归属。

候选字段类别：稳定 ID、方向、含义、地址、正常状态、数据类型、单位、关联元件、注释。

### Sequence（必填）

职责：设备动作步骤、条件、动作、完成反馈、下一步和节拍。

候选字段类别：Sequence/Step ID、显示名称、进入条件、动作、完成条件、下一步、预计时间、并行组、手动行为、重启策略。

### Interlocks（选填）

职责：动作允许、互锁、抑制及普通控制边界。安全相关项只作外部约束记录，不能由首版生成实现。

### Exceptions（选填）

职责：已知超时、异常条件、程序反应、复位和操作员说明。为空时允许生成并标记待完善。

## 4. 黄金项目集中验收输入

1. 一份用户现有机电对接表；
2. 一份电气工程师实际使用的 I/O 表；
3. 一份动作/节拍表；
4. 对应的已完成 PLC 工程；
5. 选取一个 1–2 伺服、2–4 气缸、20–60 点 I/O 的黄金项目；
6. 用户团队现有元件编号、传感器编号和步骤编号规则。

## 5. 集中验证时待确认

- 元件、信号、步骤的正式 ID 格式；
- 一个单元格怎样表达多个动作/条件，或是否拆成附表；
- PLC 地址在机械交接阶段是否允许为空；
- 串行与并行动作的表达方式；
- 手动模式、初始化、暂停、复位和掉电重启的最小必填程度；
- 伺服轴参数和厂商功能块字段放在哪一层；
- 正常开/正常关、上升沿、去抖和质量码的表达；
- 节拍估算、允许误差和并行动作计算；
- 跨工站握手、上游/下游接口和机器人/视觉接口；
- 需要生成的 LD/ST 程序风格和注释规范；
- 哪些缺失属于阻断、警告或提示。

## 6. 模板验收门

Template v1 最终验收必须用至少一套真实已完成项目做双向验证；验收前不阻塞其他可自动完成的开发：

1. 从原始资料完整迁移进模板；
2. 由不了解原项目的人根据模板理解设备；
3. 能生成正确的流程、节拍和信号时序视图；
4. 能追踪到原 PLC 程序中的主要步骤、变量和执行元件；
5. 常见缺项和冲突能被规则发现；
6. 电气工程师认为填写成本可接受；
7. 模板字段没有依赖口头解释才能使用的关键含义。
