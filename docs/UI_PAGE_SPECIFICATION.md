# UI Page Specification

本文定义第一版可点击 Demo 的完整页面地图。Demo 页面必须使用同一套示例项目和版本数据，使用户能够从项目创建一直走到在线监控和调试修改。

## 1. 全局导航与布局

### 1.1 一级导航

- Projects：项目列表；
- Templates：MachineSpec 模板与版本；
- Environment：本机厂商软件、Adapter 和模拟器；
- Settings：模型、数据与系统设置。

进入项目后显示二级导航：

- Overview；
- Specification；
- Program；
- Compile；
- Simulation；
- Release；
- Monitor；
- Versions。

### 1.2 项目全局头部

每个项目页都显示：项目名、目标 PLC、当前 MachineSpec、当前分支/Commit、能力状态和当前阶段。任何页面不能让用户不知道自己正在查看哪个版本。

### 1.3 全局状态颜色

- 灰：未开始/未检测；
- 蓝：进行中；
- 绿：通过/可用；
- 黄：受限/警告/人工步骤；
- 红：阻断/失败；
- 紫：演示数据。

## P01. Project List

**目的**：创建、搜索、恢复项目，快速看到每个项目处于哪个工程阶段。

**页面内容**

- 项目名称、客户代号（可选）、PLC 目标；
- 当前阶段：资料、生成、编译、模拟、发布、现场调试；
- 当前 Release 和最后修改时间；
- 阻断问题数量；
- Demo 示例项目入口。

**主要操作**：新建项目、打开、复制为新项目、归档、基于 Release 创建分支。

**页面状态**：空列表、正常列表、搜索无结果、加载失败、已归档筛选。

**跳转**：新建→P02；打开→项目当前阶段；Demo→P02 或指定场景。

## P02. New Project and Target Environment

**目的**：选择 PLC 品牌、系列和型号，自动匹配厂商工具能力。

**页面内容**

- 项目名称；
- PLC 品牌、系列、型号；
- 工程软件版本（自动检测后可改选）；
- 自动匹配的 Adapter、编译、模拟和监控能力；
- 安装/配置指引。

**主要操作**：重新检测、查看配置说明、保存草稿、创建项目。

**状态**：全部可用、部分可用、软件缺失、版本冲突、型号未适配、Demo 模拟状态。

**规则**：用户不选择 MCP/Connector；目标变化会使相关模板、编译和模拟结果失效。

**跳转**：创建成功→P03；环境设置→P12。

## P03. Template Center

**目的**：解释官方 Excel 各工作表并下载项目专属空白模板或完整范例。

**页面内容**

- 项目/PLC/模板/MachineSpec 版本；
- 工作表列表与必填/选填标识；
- 字段说明和示例表格；
- 填写注意事项；
- 空白模板和范例下载。

**主要操作**：切换工作表预览、下载空白模板、下载范例、进入上传。

**状态**：可下载、目标未选择、模板生成失败、模板升级、Demo 预览。

**跳转**：上传→P04；模板管理→P12。

## P04. Import Validation Workspace

**目的**：上传 Excel，定位结构、数据引用和工程逻辑问题，并协同修正。

**页面内容**

- 上传区和文件/导入版本；
- 错误、警告、建议和信息统计；
- 工作表数据网格；
- 问题列表；
- 当前问题原因、影响、来源和修复建议；
- 修改前后差异。

**主要操作**：上传/重传、直接编辑、批准 Agent 单项修正、下载标记文件、重新检查、接受非阻断风险。

**状态**：等待文件、解析中、结构失败、内容检查中、存在阻断、可进入审阅、并发版本冲突。

**规则**：原文件永久保存；Agent 不静默修改；Exceptions 为空不阻断。

**跳转**：下载模板→P03；审阅→P05。

## P05. MachineSpec Review Workspace

**目的**：在锁定前通过多种视图确认 Agent 对设备的理解。

**子页/标签**

1. Review Summary：完整性、警告、确认人；
2. Device Relationship：工站—机构—元件—信号树；
3. Process Flow：步骤与转换条件；
4. Cycle Analysis：串并行动作及节拍余量；
5. Signal Timing：命令与反馈预期波形；
6. I/O Mapping：信号、元件、地址和未分配项；
7. Interlock Matrix：选填互锁关系；
8. Exceptions：选填异常/超时/复位；
9. Raw Tables：解析后的原始规格。

**主要操作**：点击图形定位数据、修改、重新检查、逐视图确认、接受风险、锁定 MachineSpec。

**状态**：待审阅、部分确认、数据变更导致确认失效、可锁定、已锁定。

**规则**：视图数据不足时显示缺失来源，不猜测；修改会重绘并重置确认。

**跳转**：修改→P04；锁定后生成→P06。

## P06. Program Workspace

**目的**：创建 AI 分支，生成并查看程序、变量、测试和差异。

**子页/标签**

- Program Tree；
- ST Editor；
- Ladder View（能力支持时显示真实 LD）；
- Process Implementation；
- Variables & Cross References；
- Function Blocks；
- Vendor Configuration Summary；
- TestSpec；
- Requirement Traceability；
- Diff；
- Warnings/TODO。

**主要操作**：生成、编辑、提出限定范围的 AI 修改、创建 Commit、比较、恢复、下载生成包、送去编译。

**状态**：未生成、生成中、待补充、已生成未编译、编辑未保存、当前 Commit 已保存。

**规则**：程序生成后立即可见；机械看工艺实现，电气看代码/LD；关键缺失不虚构；每次修改有 Commit。

**跳转**：规格来源→P05；编译→P07；版本→P11。

## P07. Compile Workspace

**目的**：调用本机厂商编译器，读取真实诊断并完成受控修复。

**页面内容**

- 当前版本和目标环境；
- Adapter/厂商软件工作步骤；
- 错误和警告列表；
- 厂商原文、中文解释、代码/LD位置和需求来源；
- AI 修复差异；
- 编译历史。

**主要操作**：开始/停止/重试、在厂商软件打开、查看代码/需求、批准修复、新建 Commit、下载日志。

**状态**：环境不可用、准备、编译中、失败、通过有警告、通过、人工降级、任务中止。

**规则**：工程副本操作；程序/配置/工具错误分类；不触发真机下载。

**跳转**：代码→P06；通过→P08；环境→P12。

## P08. Simulation Workspace

**目的**：在厂商模拟器或软 PLC 中自动/手动验证 TestSpec。

**页面内容**

- 模拟后端和当前 Commit；
- 正常/异常测试树；
- 当前工步、虚拟输入、PLC 输出和内部变量；
- 信号波形和断言；
- Trace、快照和失败定位。

**主要操作**：运行全部/单个测试、停止、复位、切换手动模拟、改变虚拟输入、查看需求/代码、下载报告。

**状态**：后端缺失、准备、运行、通过、失败、中止、断线、人工模拟。

**规则**：只有编译通过版本可运行；真实 PLC 连接时自动测试写入禁用；失败修改必须重编译。

**跳转**：失败代码→P06；通过→P09。

## P09. Release Review and Package

**目的**：综合评审并创建正式 Release 和交付包。

**子页/标签**：概览、需求/流程、程序差异、I/O/配置、编译、模拟、风险、交付包、发布历史。

**主要操作**：处理警告、保存评审、退回、预览包、批准发布、重新导出历史包。

**状态**：条件不足、待评审、退回、打包中、已发布、发布撤回/已被新版本替代。

**规则**：结果必须属于当前 Commit；发布不下载 PLC；交付包有 MANIFEST 和版本清单。

**跳转**：退回→P06；发布→P10 或 P11。

## P10. Online Monitor and Commissioning Workbench

**目的**：工程师手工下载后，在线只读查看真实 PLC 并形成调试证据。

**页面内容**

- 连接、只读状态、PLC 型号和运行 Release；
- 模式、RUN 状态、当前步骤；
- I/O、内部变量、轴/驱动和报警位；
- Watch List、采样质量、Trace；
- Agent 对等待条件、阻断条件和数据缺失的分析；
- 现场观察记录。

**主要操作**：连接/断开、选择监控变量、开始/停止记录、保存证据窗口、询问 Agent、创建修改任务。

**状态**：未连接、只读连接、版本不匹配、断线重连、变量映射过期、采样过载、数据不完整。

**规则**：无下载/RUN/STOP/强制输出；云端上下文每次明确授权；修改建议必须创建分支。

**跳转**：创建修改→P06（新分支）；历史证据→P11。

## P11. Version Center

**目的**：统一查看规格、代码、编译、模拟、发布和现场证据的历史。

**子页/标签**：Branches、Commits、Releases、Timeline、Compare、Artifacts。

**主要操作**：选择两个版本比较、基于版本建分支、查看作者和请求、重新导出、恢复为新分支。

**状态**：正常历史、比较中、二进制只有摘要、分支冲突、工件缺失。

**规则**：历史不可删除或改写；恢复不操作真实 PLC；AI/人工来源明确。

**跳转**：Commit→对应代码/编译/模拟页；Release→P09；现场记录→P10。

## P12. Environment and Settings

**目的**：维护本机厂商工具、Adapter、模型、数据策略和模板版本。

**子页/标签**

- Local Tools：AutoShop、GX Works3、CODESYS、模拟器；
- Adapters：版本、能力、自检、日志；
- Models：云端端点、用途、连通性，本地模型占位；
- Data Policy：云端上传确认、日志目录、保留策略；
- Template Versions：当前和历史 MachineSpec 模板；
- Compatibility Matrix：PLC 型号与能力状态。

**主要操作**：重新检测、自检、查看安装说明、切换兼容版本、测试模型、更新模板。

**状态**：可用、受限、缺失、版本冲突、自检失败、更新可用。

**规则**：真实 PLC 写权限首版永久禁用；设置升级不自动破坏已有项目。

## 2. Demo 场景切换器

仅在 Demo 构建中提供隐藏或演示入口，可快速切换：

- 正常全流程；
- Excel 多个错误；
- 环境缺失；
- 编译失败后修复；
- 模拟失败后修复；
- 发布评审警告；
- 在线连接但版本不匹配；
- 历史版本恢复。

每个 Demo 页面必须显示“演示数据”，避免被误认为真实厂商能力。
