# 项目定位与技术路线（2026-08-26 定稿）

## 一、项目定位

**「非标产线双引擎 Agent——AI 编程助手 + 故障诊断医生，立足汇川国产生态」**

一句话：面向非标设备集成商的 PLC 编程提效 + 故障诊断工具，懂工艺的 AI 搭档。

- 第一步（参赛 demo）：纯软件 Agent
- 第二步（赛后产品化）：硬件盒（数据关口，数据不出厂）

## 二、两步走路线

### 第一步：纯 Agent（8月底前可交付）

```
【诊断引擎】
知识库：汇川故障手册PDF + 故障案例 + 调试记录（RAG）
Agent：DeepSeek API + Function Calling
  - read_fault_code()：解析 Er.xxx 含义+原因+排查步骤
  - read_plc_status()：读状态字/故障码寄存器（demo阶段模拟数据）
  - search_history()：查历史相似故障

【编程引擎】
输入：IO表 + 设备清单 + 工艺时序 + 安全联锁（做方案时本来就要出）
输出：ST代码 → 语法校验 →（真实闭环需接入InoProShop编译验证，后续做）

【界面】Web 对话式
```

### 第二步：硬件盒（数据关口+外置大脑）

- RK3588 盒子（约800元）接 EtherCAT 网口镜像/旁路读取数据
- 盒子职责：采集、清洗、脱敏、本地缓存、轻量异常检测、Web服务
- 大脑外置：云端API收脱敏上下文（demo阶段），客户要求高再上本地GPU
- 原始数据不出厂——这是制造业刚需卖点
