# 调研：边缘盒硬件方案（2026-08-23，架构深化）

> 老王的三连问：①3B模型太傻怎么办 ②开源没壁垒怎么办 ③设备已连PLC和MES，大电脑直接读MES不就行了，要盒子干嘛？——以下是完整答案。

## 一、市面上主流架构（三层）

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│  设备层      │     │  边缘盒（关口）     │     │  大脑（外置）  │
│             │     │                  │     │             │
│ PLC/伺服    │ ──→ │ · 协议转换         │ ──→ │ 云端API(脱敏) │
│ CNC/机器人  │     │  (Modbus/OPC-UA/  │     │ 或工厂本地    │
│ 变频器      │     │   Profinet/EtherCAT)│    │ GPU服务器    │
│             │     │ · 数据采集/清洗/脱敏 │     │             │
└─────────────┘     │ · 本地存储/断网缓存 │     └─────────────┘
                    │ · 轻量异常检测      │
                    │ · Web服务(浏览器访问) │
                    └──────────────────┘
```

**关键定位修正：盒子是"数据关口"，不是"大脑"。** 盒子上跑的是不需要智能但需要稳定的活（采集、脱敏、缓存、阈值检测）；深度推理放在云端API（收脱敏后上下文）或客户本地的GPU服务器。

## 二、为什么有 MES 还要盒子（四层答案）

1. **MES里的数据不是你要的数据**——MES存工单级业务数据（产量、良率、报工），诊断需要的是设备级高频数据（电流波形、伺服报警流水、温度、振动、报警时间戳上下文），这些在PLC里，MES大多没采或稀疏采样
2. **MES是别人的地盘**——开放接口收费、MES厂商配合度低、改配置走甲方IT流程周期以月计；盒子是**旁路接入**（网线接PLC交换机镜像数据），不动现有系统、不停产不审批，行业叫"非侵入式"，本身就是卖点
3. **IT/OT网络隔离**——办公网和产线网物理隔离，大电脑想连产线网安全审批过不了，盒子是OT侧摆渡节点
4. **最关键：目标客户根本没MES**——MES完善的厂（比亚迪、宁德）有自己的数字化部门不需要你；**市场恰恰是设备没联网、没MES、全靠老师傅的非标设备和中小企业**——盒子是给"没有数据基础设施的工厂"补课的

| 硬件 | 价格 | AI算力 | 能干什么 | 结论 |
|------|------|--------|---------|------|
| **RK3588盒子**（香橙派5 Plus/工业款） | **约800-900元** | 6 TOPS NPU | 数据关口全部职责；轻量推理 | ✅ **首选**：成本低、有实测案例（200人五金厂部署，单用户响应5秒内）、无风扇、路演能带实物、国产芯片讲信创故事 |

## 四、盒子软件栈（全开源）

```
数据采集：pymodbus / OPC-UA客户端
大模型：Ollama + Qwen2.5（轻量层）
知识库：LangChain + ChromaDB（设备手册、故障案例、维修记录）
Agent编排：Function Calling
Web界面：Gradio/Flask
部署五步：①知识库文档 ②向量库 ③Ollama部署 ④封装智能体 ⑤Docker容器化
```

## 五、开源没壁垒——壁垒根本不在软件

工业AI这行软件从来不是壁垒（卡奥斯、羚羊、浪潮拿了工信部典型案例的，软件层也是开源货攒的），壁垒在三样：

| 壁垒 | 为什么别人做不了 | 老王有没有 |
|------|----------------|-----------|
| **行业故障知识库** | 大模型没见过非标设备故障案例就是睁眼瞎，案例要人喂 | ✅ 十几年非标设备经验 |
| **现场工程能力** | 协议对接、电柜走线、产线旁调试，又脏又累，互联网公司没人干 | ✅ 跑了十几年现场 |
| **数据飞轮** | 每部署一台，知识库厚一分 | ✅ 每个客户都是积累 |

**定性：不是"包装开源"，是把开源组件集成到别人进不去的工业现场——集成和落地本身就是工程项目，机械设备行业拼的从来不是谁发明零件，是谁能把整台设备调通交付。**

## 六、不需要接笔记本

盒子自己起 Web 服务，产线旁任何电脑/手机浏览器输个 IP 就能用。笔记本只是开发调试阶段的事。
