## 三、IoT 平台开源项目

### simple-iot（dingdaoyi）—— 单 jar 部署神器

**GitHub**：`github.com/dingdaoyi/simple-iot`

| 维度 | 内容 |
|------|------|
| 技术栈 | Spring Boot 4 单 jar · Java 25 虚拟线程 · Vue 3 SPA |
| 部署 | 一个 95MB jar + dist 目录 |
| 内存 | 512MB 起步 |
| 协议 | Modbus-RTU/TCP、OPC UA、自定义二进制、自定义 JSON |
| MQTT broker | **内置**（mica-mqtt，进程内直连）|
| 性能 | p99 延迟 1ms 以内（10万消息/秒）|
| 热加载 | 协议脚本运行时上传 |
| 真实项目 | 200 台 PLC 接入，数据不出内网 |

**核心创新**：
- ✅ 单进程单 jar 部署
- ✅ 内置 MQTT broker
- ✅ 热加载协议脚本
- ✅ 虚拟线程

### JetLinks（开源，国产）

**GitHub**：`github.com/jetlinks/jetlinks-community`

| 维度 | 内容 |
|------|------|
| 语言 | Java + Spring WebFlux（响应式）|
| 协议 | MQTT、Modbus、TCP、CoAP 等 30+ |
| 数据库 | PostgreSQL + Redis + MongoDB + ElasticSearch |
| 规则引擎 | 自带可视化规则链 |

### ThingsBoard CE

**GitHub**：`github.com/thingsboard/thingsboard`

适合大规模（百万级）部署，**老王 AI BOX 场景不推荐**。
