## 零、给 Codex 的开篇说明

### 项目背景

老王是非标机械工程师转型 AI FDE 的项目：
- 老王本人：懂 PLC 基础（大学学过梯形图/ST），但很多忘了，**不会写代码**
- 合伙人：电气工程师，**熟悉汇川 AutoShop 和西门子 TIA Portal**
- 客户：使用国产 PLC（汇川/三菱）的中型工厂

### 项目愿景

把"AI 写 PLC 程序"做成一个**本地工具**（类似 VSCode + Continue 的体验）：
- 电气工程师用 AI 助手写 PLC 程序
- 自然语言 → ST/SCL 代码 → 编译 → 通过率 > 80%
- 故障诊断作为副线增值
- AI 盒子是后期扩展

### 核心约束（必须遵守）

### 模块 1：LLM 客户端（core/llm/）

#### 1.1 功能

封装 Ollama + DeepSeek 的调用，支持多种模型切换。

#### 1.2 接口设计

```python
# core/llm/base.py
from abc import ABC, abstractmethod
from typing import List, Dict, AsyncIterator

class BaseLLMClient(ABC):
    """LLM 客户端基类"""
    
    @abstractmethod
    async def chat(
        self,
        messages: List[Dict[str, str]],
        temperature: float = 0.2,
        max_tokens: int = 4096,
        **kwargs
    ) -> str:
        """同步对话"""
        pass
    
    @abstractmethod
    async def stream_chat(
        self,
        messages: List[Dict[str, str]],
        temperature: float = 0.2,
        max_tokens: int = 4096,
        **kwargs
    ) -> AsyncIterator[str]:
        """流式对话"""
        pass
    
    @abstractmethod
    async def embed(
        self,
        texts: List[str]
    ) -> List[List[float]]:
        """文本向量化"""
        pass
    
    @abstractmethod
    async def health_check(self) -> bool:
        """健康检查"""
        pass
```

#### 1.3 实现

```python
# core/llm/ollama_client.py
import httpx
from typing import List, Dict, AsyncIterator
from core.llm.base import BaseLLMClient

class OllamaClient(BaseLLMClient):
    """Ollama 客户端（本地 DeepSeek/Qwen 等）"""
    
    def __init__(self, base_url: str = "http://localhost:11434"):
        self.base_url = base_url
        self.client = httpx.AsyncClient(timeout=60.0)
    
    async def chat(
        self,
        messages: List[Dict[str, str]],
        temperature: float = 0.2,
        max_tokens: int = 4096,
        model: str = "deepseek-coder:6.7b",
        **kwargs
    ) -> str:
        """
        同步对话
        默认模型: deepseek-coder:6.7b（代码能力强，7B 可装在 AI BOX）
        """
        response = await self.client.post(
            f"{self.base_url}/api/chat",
            json={
                "model": model,
                "messages": messages,
                "stream": False,
                "options": {
                    "temperature": temperature,
                    "num_predict": max_tokens,
                }
            }
        )
        response.raise_for_status()
        return response.json()["message"]["content"]
    
    async def stream_chat(
        self,
        messages: List[Dict[str, str]],
        temperature: float = 0.2,
        max_tokens: int = 4096,
        model: str = "deepseek-coder:6.7b",
        **kwargs
    ) -> AsyncIterator[str]:
        """流式对话（SSE）"""
        async with self.client.stream(
            "POST",
            f"{self.base_url}/api/chat",
            json={
                "model": model,
                "messages": messages,
                "stream": True,
                "options": {
                    "temperature": temperature,
                    "num_predict": max_tokens,
                }
            }
        ) as response:
            async for line in response.aiter_lines():
                if line:
                    import json
                    data = json.loads(line)
                    if "message" in data:
                        yield data["message"]["content"]
    
    async def embed(
        self,
        texts: List[str],
        model: str = "bge-large-zh-v1.5"
    ) -> List[List[float]]:
        """文本向量化（使用 BGE 中文模型）"""
        embeddings = []
        for text in texts:
            response = await self.client.post(
                f"{self.base_url}/api/embeddings",
                json={"model": model, "prompt": text}
            )
            response.raise_for_status()
            embeddings.append(response.json()["embedding"])
        return embeddings
    
    async def health_check(self) -> bool:
        """健康检查"""
        try:
            response = await self.client.get(f"{self.base_url}/api/tags")
            return response.status_code == 200
        except Exception:
            return False
    
    async def close(self):
        await self.client.aclose()


# core/llm/factory.py
def create_llm_client(provider: str = "ollama", **kwargs) -> BaseLLMClient:
    """LLM 客户端工厂"""
    if provider == "ollama":
        return OllamaClient(**kwargs)
    # 未来扩展：openai、anthropic 等
    raise ValueError(f"Unknown provider: {provider}")
```

#### 2.2 整体架构

```python
# core/generator/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum

class PLCVendor(Enum):
    INOVANCE = "inovance"      # 汇川 AutoShop
    SIEMENS = "siemens"          # 西门子 TIA Portal
    CODESYS = "codesys"          # CODESYS
    MITSUBISHI = "mitsubishi"    # 三菱 GX Works

class PLCLanguage(Enum):
    ST = "st"                    # 结构化文本
    SCL = "scl"                  # 西门子 SCL
    LADDER = "ladder"            # 梯形图
    FBD = "fbd"                  # 功能块图

@dataclass
class GenerationRequest:
    """代码生成请求"""
    vendor: PLCVendor
    language: PLCLanguage
    natural_language: str        # 自然语言工艺描述
    plc_model: str                # PLC 型号（如 "汇川 H5U"）
    io_table: List[Dict]         # I/O 分配表
    flow_diagram: str = None     # 流程图（可选，base64 或路径）
    reference_programs: List[str] = None  # 参考程序
    
@dataclass
class GenerationResult:
    """代码生成结果"""
    code: str                     # 生成的代码
    language: PLCLanguage
    explanation: str              # 代码说明
    confidence: float            # 置信度 0-1
    warnings: List[str]           # 警告
    metadata: Dict                # 元数据（token 用量等）

class BaseCodeGenerator(ABC):
    """代码生成器基类"""
    
    @abstractmethod
    async def generate(self, request: GenerationRequest) -> GenerationResult:
        pass
    
    @abstractmethod
    def get_prompt_template(self) -> str:
        """获取提示词模板"""
        pass
```

#### 2.5 汇川生成器实现

```python
# core/generator/inovance_generator.py
import re
from typing import List
from core.generator.base import (
    BaseCodeGenerator, GenerationRequest, GenerationResult, 
    PLCVendor, PLCLanguage
)
from core.llm.base import BaseLLMClient
from prompts.generator.st_generator import ST_GENERATOR_PROMPT

class InovanceGenerator(BaseCodeGenerator):
    """汇川 PLC 代码生成器"""
    
    SYSTEM_PROMPT = """你是汇川 AutoShop 编程专家。
熟悉汇川 H5U、H3U、AM600、AC800 等系列 PLC 的 ST 语言编程。
精通 IEC 61131-3 标准，擅长非标自动化设备控制程序。
代码必须可直接在 AutoShop 中编译通过。"""
    
    def __init__(self, llm_client: BaseLLMClient):
        self.llm = llm_client
    
    async def generate(self, request: GenerationRequest) -> GenerationResult:
        if request.vendor != PLCVendor.INOVANCE:
            raise ValueError("InovanceGenerator 只支持汇川 PLC")
        
        # 1. 构造提示词
        prompt = self._build_prompt(request)
        
        # 2. 调用 LLM
        messages = [
            {"role": "system", "content": self.SYSTEM_PROMPT},
            {"role": "user", "content": prompt}
        ]
        response = await self.llm.chat(messages, temperature=0.2)
        
        # 3. 解析结果
        code = self._extractcode(response)
        warnings = self._check_code(code)
        
        return GenerationResult(
            code=code,
            language=request.language,
            explanation=response,
            confidence=0.85,
            warnings=warnings,
            metadata={}
        )
    
    def _build_prompt(self, request: GenerationRequest) -> str:
        io_table_str = self._format_io_table(request.io_table)
        return ST_GENERATOR_PROMPT.format(
            vendor="汇川 Inovance",
            language=request.language.value,
            device_type="非标自动化设备",
            plc_model=request.plc_model,
            programming_software="AutoShop",
            protocol="Modbus TCP / Profinet / EtherCAT",
            io_table=io_table_str,
            natural_language=request.natural_language,
            reference_programs="\n".join(request.reference_programs or [])
        )
    
    def _format_io_table(self, io_table: List[Dict]) -> str:
        """格式化 I/O 分配表"""
        lines = ["| 地址 | 名称 | 类型 | 说明 |", "|------|------|------|------|"]
        for item in io_table:
            lines.append(
                f"| {item['address']} | {item['name']} | "
                f"{item.get('type', 'DI')} | {item.get('description', '')} |"
            )
        return "\n".join(lines)
    
    def _extract_code(self, response: str) -> str:
        """从 LLM 响应中提取代码块"""
        code_blocks = re.findall(
            r'```(?:st|scl|ladder)?\n(.*?)\n```',
            response,
            re.DOTALL
        )
        return "\n\n".join(code_blocks) if code_blocks else response
    
    def _check_code(self, code: str) -> List[str]:
        """代码预检查（粗筛）"""
        warnings = []
        
        # 检查急停
        if "急停" not in code and "Emergency" not in code and "EMG" not in code:
            warnings.append("⚠️ 未发现急停逻辑")
        
        # 检查超时
        if "TON" not in code and "超时" not in code:
            warnings.append("⚠️ 未发现超时保护")
        
        # 检查注释
        comment_count = code.count("//") + code.count("(*")
        if comment_count < 3:
            warnings.append("⚠️ 注释较少，建议补充")
        
        return warnings
    
    def get_prompt_template(self) -> str:
        return ST_GENERATOR_PROMPT
```

### 模块 3：编译验证（core/compiler/）

#### 3.1 功能

调用 PLC 编程软件（AutoShop/TIA Portal）命令行编译，验证 AI 生成代码是否能编译通过。

#### 3.2 接口设计

```python
# core/compiler/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum

class CompileStatus(Enum):
    SUCCESS = "success"
    WARNING = "warning"
    ERROR = "error"
    TIMEOUT = "timeout"
    UNKNOWN = "unknown"

@dataclass
class CompileResult:
    """编译结果"""
    status: CompileStatus
    code: str                     # 原始代码
    stdout: str                   # 标准输出
    stderr: str                   # 错误输出
    errors: List[Dict]            # 错误列表（结构化）
    warnings: List[Dict]          # 警告列表
    compile_time: float           # 编译耗时（秒）
    output_file: str = None       # 输出文件路径
    
    @property
    def is_success(self) -> bool:
        return self.status == CompileStatus.SUCCESS

class BaseCompiler(ABC):
    """编译器基类"""
    
    @abstractmethod
    async def compile(
        self,
        code: str,
        project_path: str = None,    # TIA Portal 项目路径
        output_path: str = None       # 编译产物输出路径
        timeout: int = 60
    ) -> CompileResult:
        """编译代码"""
        pass

# core/compiler/auto_fixer.py
from typing import List
from core.llm.base import BaseLLMClient
from core.compiler.base import CompileResult, CompileStatus

class AutoFixer:
    """AI 自动修复编译错误"""
    
    MAX_ITERATIONS = 3  # 最多修复 3 轮
    
    def __init__(self, llm_client: BaseLLMClient):
        self.llm = llm_client
    
    async def fix_until_success(
        self,
        code: str,
        compile_func,
        vendor: str
    ) -> CompileResult:
        """循环修复直到编译成功"""
        current_code = code
        
        for i in range(self.MAX_ITERATIONS):
            result = await compile_func(current_code)
            
            if result.is_success:
                return result
            
            # 调用 LLM 修复
            current_code = await self._fix_code(
                current_code, result, vendor
            )
        
        return result  # 返回最后的结果

        self,
        code: str,
        result: CompileResult,
        vendor: str
    ) -> str:
        """LLM 修复代码"""
        prompt = f"""以下 PLC 代码编译失败，请修复后重新输出完整代码。

# 原代码
```
{code}
```

# 编译错误
{result.stderr}

# 错误详情（结构化）
{self._format_errors(result.errors)}

# 要求
1. 只修复错误，不要改动逻辑
2. 输出完整代码（不要省略）
3. 保留所有注释
4. 保持命名规范

```st

```
"""
        messages = [{"role": "user", "content": prompt}]

        port: int = 502,
        unit_id: int = 1,

        self.port = port
        self.unit_id = unit_id

        )

        self,
        address: int,
        count: int = 1
    ) -> List[int]:
        """读取保持寄存器（异步包装）"""
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            None,
            self._client.read_holding_registers,
            address, count, self.unit_id
        )
        if result.isError():
            raise Exception(f"Modbus read error: {result}")
        return result.registers
    
    async def read_input_registers(
        self,
        address: int,
        count: int = 1
    ) -> List[int]:
        """读取输入寄存器"""
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            None,
            self._client.read_input_registers,
            address, count, self.unit_id
        )
        if result.isError():
            raise Exception(f"Modbus read error: {result}")
        return result.registers
    
    async def write_register(self, address: int, value: int):
        """写入单个寄存器"""
        loop = asyncio.get_event_loop()

## 七、关键技术决策

### 决策 1：为什么用 Dify 而不是自己写 Agent？

```yaml
Dify 优点:
  - 13万 星，成熟稳定
  - 可视化编排
  - 支持多种模型
  
为什么不直接用:
  - 太多功能我们用不上
  - 增加系统复杂度
  
我们的方案:
  - 借鉴 Dify 的多智能体思路
  - 自己实现简化版（core/agent/）
  - 保留核心的多 Agent 协同能力
```

### 决策 2：为什么优先汇川？

```yaml
原因:
  - 国内 PLC 市场国产占 50%+，汇川占大头
  - 老王合伙人熟悉汇川 AutoShop
  - 避开西门子护生态（的60万+ 用户基数）
  - 汇川 iFG 工业智脑已集成 AI 代码生成（可参考）

优先级:
  P0: 汇川 AutoShop ST 代码生成 + 编译验证
  P1: 西门子 TIA SCL 代码生成（参考 RealPLC）
  P2: CODESYS ST 代码生成（参考 RealPLC CODESYS）
```

### 决策 3：为什么不一开始就用云端 LLM？

```yaml
云端问题:
  - 工厂数据不能出网（核心约束）
  - API 调用费用
  - 网络延迟
  - 隐私合规

本地部署:
  - Ollama 一键启动
  - DeepSeek-R1 7B/14B 可装在 AI BOX
  - 完全私有化
  - 零费用
```
